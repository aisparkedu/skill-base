# 决策矩阵

## 工作流
1. **列选项**：列出所有备选方案。
2. **定标准**：什么最重要？（成本、时间、质量、风险、愉悦感……）
3. **赋权重**：哪些标准最重要？（权重 1–5）
4. **打分**：每个选项在每个标准上打分（1–5）。
5. **出矩阵**：选项 × 标准 的表格，算加权得分。
6. **分析**：哪个选项胜出？有哪些取舍？
7. 结尾给清晰结论："如果你看重 X → 选 A；如果你看重 Y → 选 B。"

## 规则
- 别替用户做决定 —— 是照亮选择，不是代替选择。
- 提示可能的偏误（沉没成本、维持现状……）。
- 打分前先问清标准。
