# 总结图规划（两种风格共用）

## 目标

将一篇文章浓缩成一组能够独立阅读的公众号图文。读者只看图片就能理解主题、核心结论、必要方法和适用条件。图片是主要内容。

## 提炼与分图

1. 提取文章的核心判断、支撑要点、关键步骤、具体例子和必要限制。删除铺垫、重复表达和与主线无关的旁支。
2. 一页承担一个主要任务。可采用总览、对比、机制、操作、实例、清单等形式。按信息量决定张数，不固定四张，不强套教程步骤。
3. 首图交代主题与收益，给出有用结论或阅读路径；不能只有吸引点击的标题。
4. 中间页保留让结论成立、让操作可执行的信息。例如“模板里写指令”应保留填写位置、字段与实际指令，不能只画一个文本图标。
5. 末页可收束为结论、选择建议或行动清单；只在原文包含操作时总结步骤。

本次获认可的四图只是示例：价值与路径 → 配置项 → 填写实例 → 验证与扩展。观点文章或评测不必采用此顺序。

## 每页计划

记录页码、文件名、本页核心结论、标题、概述、完整正文与标签、页脚结语、图解结构、内容在原文中的依据。风格单独记录，便于同文案做不同风格对照。

每页通常以120–220字作为密度起点，依内容和画布调整；必要信息放不下时增页，不靠缩小字体硬塞。短页不凑字数，重要限制不为视觉整齐而删除。标题醒目，正文清楚，插画解释信息，三者共同承载内容。

## 内容对应的图解

- 连续操作：顺序箭头，检查后才进入保存等后续动作。
- 并列要点：分栏或分区，不画因果箭头。
- 比较：对应维度逐项对齐，结论依原文证据。
- 输入输出：准确说明中间动作，运行前后有实际差别。
- 字段或代码：字段、解释、实例各自清楚；代码字符准确，另存纯文本。
- 操作界面：抽象说明图标明为示意，不能拿生成界面充当真实截图。

## 整套检查

脱离原文连续读图：能否说出文章主张、支撑理由和必要行动？有无逻辑断点、术语未解释、关键步骤遗漏？每页是否有独立信息增量？图组中重复提示仅为导航服务。

进行新旧风格对照时固定文章、核心文案和页序；允许为了阅读调整换行、分区和图形表现，不擅自增删结论。
